# Types opened by default in Sublime Text. scripts/setup-sublime.sh sets the
# LaunchServices handler for each non-comment line, skipping the ones already
# pointing at Sublime. Edit + re-run `make sublime` to apply.
#
# A line is a UTI or a bare file extension (no dot). Extensions are resolved to
# a UTI before anything is written, and an extension no installed app declares
# has no real UTI - it resolves to a throwaway `dyn.*` type that LaunchServices
# will not attach a handler to. That covers most of what you would want here
# (.rs, .go, .toml, .lua, .tf, ...): those files have no default opener to set,
# so listing them does nothing. Prefer UTIs; keep the list to types that exist.

# Broad categories. public.text is wide (also catches .rtf etc.); drop it if you
# want only plain text + code. Neither cascades to a child type another app
# claims by name, which is why the specific types below are listed too.
public.plain-text
public.text
public.source-code

# Deliberately left out:
