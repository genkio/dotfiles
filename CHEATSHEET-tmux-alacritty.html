tmux + Alacritty cheatsheet

Prefix: C-j or C-f or C-Right Copy mode: vi keys Reload: prefix r Describe a key: prefix / All keys: prefix ?

tmux is a stock tmux default worth knowing. plugin comes from a TPM plugin. Everything unmarked is custom, from tmux/.tmux.conf, tmux/bin/, or alacritty.toml.

Navigate, resize, close

C-h C-k C-lNo prefix. Move left / up / right. There is no C-j — see the gotcha below
prefix ←↑↓→Move in any direction, including down. Repeatabletmux
prefix qShow pane index numbers; press a number to jump
prefix ;Last panetmux
prefix M-←↑↓→Resize by 5 cells, repeatable (C-←↑↓→ for 1)tmux
prefix xKill the pane, after a y/n confirm. Survivors rebalance
prefix XKill every other pane in the window, after a y/n confirm
prefix yToggle synchronize-panes (type into every pane at once)
prefix CSet or edit this pane's label, shown in its border

Zoom no prefix

C-z / C-UpFull zoom toggle. Two keys for one action, so a phone keyboard can reach it
C-xHalf zoom: fill the column (full height)
C-yHalf zoom: fill the row (full width)
Half zoom is per-axis and per-pane, so a left and a right pane can both be maxed. Press the same key again to restore

Alacritty — transparent titlebar, OSC 52 clipboard, option as alt. No splits or tabs; tmux does that

Keys

⇧EnterInsert a newline instead of submitting, for a multi-line prompt
⌘⇧SpaceToggle Alacritty's own vi mode. Not the default C-⇧Space, which a CJK input method eats
⌘⇧YJoin the clipboard into one line. Run it after a vi-mode y; Alacritty can't filter a yank as it happens
⌘⇧U ⌘⇧D ⌘⇧J ⌘⇧KScroll the Claude Code transcript
⌘0Reset the font sizealacritty
⌘1..⌘9, ⌘⇧N/PPassed through to tmux for windows and sessions — see above

Good to know

ThemeFlexoki Light / TokyoNight Storm, switched by prefix t (or scripts/theme-toggle.sh outside tmux). Alacritty reloads its config live, so the change is instant
ClipboardOSC 52 both ways, which is what makes copy work from a remote tmux
Cmd chordsCmd never reaches the terminal program, so these are emitted as private escape sequences and caught in .tmux.conf as user-keys. The two files must be kept in sync.
Scrollback10000 lines, matching tmux's history-limit

Gotchas worth knowing

The prefix beats every other binding. tmux checks "is this the prefix?" before it looks in the current key table or the root table. Because the prefix here is C-j (and C-f), no binding on those keys can ever fire: that's why pane-down is C-k's neighbour prefix ↓ rather than C-j, and why copy mode uses NPage/C-d for page-down instead of the usual C-f.

Reloading adds bindings but never removes them. prefix r picks up new and changed keys, but a binding you deleted from the config stays live until the server restarts.

These Ctrl keys never reach your shell. C-h C-k C-l C-n C-p C-x C-y C-z C-j C-Right are all claimed by tmux, so readline loses clear-screen, kill-line, yank, history and suspend at the prompt. That's the price of prefix-free pane navigation.

prefix p is the PR popup, not "previous". Previous session is ⌘⇧P or prefix (. Previous window is C-p.

Ctrl with the - key is one key, spelled three ways. C--, C-_ and C-/ all send the same byte (0x1F, ASCII US), which tmux names C-_ — the same reason Emacs undo answers to both C-/ and C-_. So copy mode has one binding, not three.
